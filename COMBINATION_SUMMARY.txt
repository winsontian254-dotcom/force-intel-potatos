BUILD INSTRUCTIONS
================================================================================

Prerequisites:
  • Java 17 or later
  • Gradle (included via wrapper)

Build command:
  cd UltraOptimize
  ./gradlew build

Output:
  build/libs/ultraoptimize-[version]-forge.jar

Installation:
  1. Place JAR in .minecraft/mods/
  2. Launch Minecraft with Forge
  3. Mods should appear in mod list
